# HW1：台灣本島地形高度分佈

資料分析與視覺化課程作業一。用 D3.js v7 做的靜態視覺化，從空間分布、地形結構、統計分布、人的尺度四個互補角度呈現台灣本島（不含澎湖、金門、馬祖）的地形高度。

完整設計決策與實作紀錄見 [`PLAN.md`](PLAN.md)。

## 預覽

```
cd hw1
python3 -m http.server 8000
```

再用瀏覽器開 http://localhost:8000/ 即可，不需要建置工具。

## 內容

- **分層設色地形圖**：`d3.contours()` 疊出綠→黃→棕→白的填色帶，呈現整體地形空間分布
- **等高線圖**：每 500m 一條等高線，標註玉山、雪山等主要高峰
- **面積—高程分佈直方圖**：各高程區間佔本島總面積的百分比
- **剖面圖**：沿北緯 23.47°（通過玉山）東西向切過中央山脈的海拔剖面

## 資料來源

Copernicus GLO-30 DEM（30m 解析度），AWS Open Data Registry `s3://copernicus-dem-30m`（免金鑰）。本島邊界由 DEM 高程資料自身推導（陸地遮罩 + 連通元件分析取最大陸塊），未使用外部邊界檔。前處理腳本見 `scripts/`，產出資料見 `data/`。
