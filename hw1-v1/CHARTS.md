# 兩張圖怎麼畫的

整體規劃見 [`PLAN.md`](PLAN.md)。技術：Vue 3 負責畫面，D3 只負責計算（比例尺、等值線、路徑），SVG 由 Vue 模板輸出。

## 資料流程

```
Copernicus GLO-30 DEM (30m)
  → scripts/process_dem.py（Python，離線處理一次）
      ├─ public/data/taiwan-dem-grid.json   高程網格 → View 1
      └─ public/data/elevation-bands.json   各高程區間面積佔比 → View 2
  → src/components/*.vue 讀取並畫圖
```

- 前處理：拼接圖磚、降採樣、用「高度 > 0」找陸地，再只保留最大連通區塊（台灣本島，自動排除離島）。
- 海洋與離島格填 `-9999`，畫等值線時自然被排除，不需要另外的海岸線檔。

## 共用設定（`src/constants.js`）

兩張圖共用同一組門檻與顏色，同一個顏色在兩張圖中代表同一個高度：

- 門檻：`0 / 100 / 500 / 1000 / 1500 / 2000 / 2500 / 3000 / 3500` m
- 顏色：綠 → 黃 → 棕 → 亮橘（3500 m 以上用亮橘突顯玉山一帶）

## View 1：分層設色地形圖

`HypsometricMap.vue`　回答：哪裡高、哪裡低？

**步驟**

1. **載入資料**：讀 `taiwan-dem-grid.json`，取得 `width`、`height`、`bbox`、`values`（高程扁平陣列，海洋 = −9999）。
2. **算尺寸**：每格放大 2.2 px。經度 1° 的實際長度隨緯度變短，所以寬度乘 `cos(平均緯度)`，台灣才不會被拉寬。
3. **建立座標轉換**：`d3.geoTransform` 自訂 `point(x, y)`，把「格子的列／欄索引」乘上 2.2；再用 `d3.geoPath` 把形狀轉成 SVG path 字串。
4. **產生色帶形狀**：
   ```js
   d3.contours().size([width, height]).thresholds(ELEVATION_THRESHOLDS)(values)
   ```
   每個門檻得到一個多邊形，範圍是「高度 ≥ 該門檻」。0 m 最大，3500 m 最小。海洋 −9999 不在任何範圍內，自然留白。
5. **上色並疊圖**：模板用 `v-for` 把 9 個多邊形畫成 `<path>`，`fill` 取對應色。順序由低到高，後畫的高海拔蓋在前面的低海拔上，形成一圈圈色帶。
6. **海岸輪廓**：把 0 m 那個多邊形再畫一次，只描邊不填色。
7. **圖例**：右側 9 列，每列一個色塊 `<rect>` + 區間文字 `<text>`。

### 色帶與外框怎麼來

圖上只有「填色色帶」和「一圈海岸外框」，沒有一條條標示高度的等高線。

**資料**：`taiwan-dem-grid.json` 是 200×260 的格子，每格一個海拔值（`values` 為攤平的一維陣列）。本島格 = 平均海拔（公尺），海洋與離島格 = `-9999`。

**色帶**：`d3.contours()` 用 marching squares 演算法，對每個門檻找出高度跨過門檻的邊界，連成封閉多邊形，範圍是「高度 ≥ 門檻」：

- ≥0 m：整個本島（最大）
- ≥100 m：扣掉最低的平原
- …
- ≥3500 m：只剩玉山附近（最小）

9 個多邊形只填色、不描邊，由大到小依序畫，高海拔蓋在低海拔上，露出的環狀部分就是色帶。色帶交界看起來像等高線，其實只是兩種顏色相接。

**外框（海岸線）**：不用外部海岸線檔，直接用 ≥0 m 那個多邊形：

1. 前處理時把「高度 > 0」當陸地，只保留最大連通區塊（本島），其餘（海洋、澎湖、金門、馬祖）填 `-9999`。
2. `-9999` 小於 0，不會被包進 ≥0 m 的多邊形，所以它的邊緣剛好就是本島輪廓。
3. 把同一個多邊形再畫一次，`fill: none`、只描邊（深褐色 0.6 px），就是外框。

**座標轉換**：contours 輸出的是格子的欄、列索引，不是經緯度。`d3.geoTransform` 把每個點乘上 2.2 px，`d3.geoPath` 轉成 SVG path；整個地圖 `<g>` 再加 `scale(cos(緯度), 1)` 壓縮水平方向。

**限制**：

- 每格約 850 m，輪廓是平滑過的，不是精確海岸線。
- 海拔 ≤0 m 的低窪處會被當成海。
- 若要真正的等高線，需另外對每個 contour 加 `stroke`，目前沒有做。

為什麼用分層而非連續漸層：這是地形圖慣例，一眼就能分平原、丘陵、高山。代價是同一色帶內看不出漸變。

## View 2：面積—高程分佈直方圖

`ElevationHistogram.vue`　回答：多少比例的土地在哪個高度？

**步驟**

1. **載入資料**：讀 `elevation-bands.json`，取得 9 個區間，每個有 `min_m`、`max_m`、`pct_of_island`（面積佔比 %），另有總面積。
2. **建 y 軸比例尺**：`d3.scaleBand`，把 9 個區間由上到下等距排開，`padding(0.25)` 留出條與條的間隙，並提供每條的高度 `bandwidth()`。
3. **建 x 軸比例尺**：`d3.scaleLinear`，範圍從 0 到最大佔比的 1.1 倍（多留 10% 放數值），對應到繪圖區寬度。
4. **畫 x 軸**：用 `x.ticks(5)` 取 5 個刻度，每個刻度畫一條短線和「N%」文字。
5. **畫每一列**：模板用 `v-for` 對 9 個區間各畫三樣東西：
   - 左側區間文字（如「100–500m」）
   - 長條 `<rect>`：寬度 = `x(佔比)`，高度 = `bandwidth()`，顏色沿用 View 1
   - 長條右側的百分比文字
6. **註記**：左下角標本島總面積（估算值）。
